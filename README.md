# MakHos · Little Legends

หมากฮอสไทยบนเว็บมือถือ/แท็บเล็ต พร้อมหมากทหาร 3D และโหมดผจญภัย

## เล่นและพัฒนาในเครื่อง

ใช้ Node.js 24 และ pnpm 11.25.0

```sh
pnpm install
pnpm dev
```

เปิด http://localhost:5173 สำหรับตัวเกม หากต้องการห้องออนไลน์ เปิดอีก terminal:

```sh
pnpm server
```

Vite ส่ง `/api` ไป backend ที่พอร์ต 8787 ให้อัตโนมัติ กด **เล่นออนไลน์ → เชื่อมต่อออนไลน์** แล้วสร้างห้องหรือจับคู่แรงค์ ทดสอบผู้เล่นที่สองด้วยคนละเบราว์เซอร์/โปรไฟล์ (แท็บในโปรไฟล์เดียวกันใช้บัญชีเดียวกัน)

## ฟีเจอร์ v0.1

- หมากฮอสไทย 8 ตัว บังคับกิน กินต่อด้วยตัวเดิม ฮอสบินและลงติดหลังตัวที่กิน กินย้อนทิศทันทีได้เมื่อช่องเปิด ขึ้นฮอสแล้วจบตา
- ด่านบอต 4 ด่าน: มาตรฐาน, หลุม, 6 ต่อ 6 กับก้อนหิน, บอสราชาทองคำ; คิดด้วย minimax ใน Web Worker
- หมาก 3D สร้างจาก geometry ในโค้ด มีท่ายืน การเคลื่อนที่/กระโดดกิน ฮอสตัวใหญ่พร้อมมงกุฎ และเอฟเฟกต์กิน 2 แบบ
- เหรียญผจญภัย, ชุดหมาก 3 สี, กระดานครึ่งฝั่ง, เอฟเฟกต์ พร้อมบันทึกใน localStorage
- คำใบ้ ย้อนลองเดินใหม่ เล่นสองคนเครื่องเดียว ลดการเคลื่อนไหว และกระดาน 2D สำหรับคีย์บอร์ด
- เลย์เอาต์แนวตั้ง/แนวนอนต่างกัน ช่องพิมพ์ HTML 18px และ VisualViewport รองรับแป้นพิมพ์ โดยไม่ปิด pinch zoom
- Backend ตรวจตาเดิน ห้องรหัส 8 ตัว แชต จับคู่แรงค์ Elo เหรียญออนไลน์ ซื้อ/เลือกของตกแต่ง และกลับเข้าห้องหลังหลุด (ภายใน 2 นาที)
- SQLite บันทึกบัญชี guest คะแนนและของตกแต่ง แยกกระเป๋าออนไลน์จากผจญภัยในเครื่อง

เกมนี้กำหนดเสมอเมื่อตำแหน่งซ้ำ 3 ครั้ง หรือครบ 80 ตาย่อยที่ไม่มีการกิน/ขึ้นฮอส เป็นกติกาเสมอของผลิตภัณฑ์นี้ ไม่อ้างเป็นข้อบังคับการแข่งขันไทยทุกแห่ง

อ้างอิงกติกาการเดินไทย: [FMJD variants](https://www.fmjd.org/downloads/variants/Checkers_families_and_rules_28-9-2018.pdf), [Jocly Thai Draughts](https://hgm.nubati.net/jocly/jocly-master/dist/browser/games/checkers/rules-thai-draughts.html)

## ตรวจสอบ

```sh
pnpm test

```

ชุดทดสอบครอบคลุมการบังคับกิน/กินต่อ/ฮอส/การเลื่อนยศ/หลุม/หิน/บอต และเซิร์ฟเวอร์สองฝั่ง รวมตาผิด การส่งซ้ำ แชต เหรียญและแรงค์

## GitHub Pages

workflow `.github/workflows/pages.yml` ทดสอบและ build เมื่อ push เข้า `main` แล้ว deploy โฟลเดอร์ `dist` ไป Pages

เปิด repository Settings → Pages → Source: **GitHub Actions** ก่อนใช้ workflow หรือรัน workflow ด้วยมือหลังตั้งค่า

Vite ใช้ `base: './'` เพื่อรองรับ URL ใต้ชื่อ repository เช่น `/MakHos/`

**Pages เสิร์ฟเฉพาะหน้าเกม** บอต/ด่านเล่นได้โดยไม่ต้องมี backend แต่ห้องออนไลน์ต้องมี backend HTTPS ด้านล่าง แล้วกรอก URL ใน **เล่นออนไลน์ → ตั้งค่าเซิร์ฟเวอร์**

## Backend สำหรับใช้งานข้ามเครื่อง

เซิร์ฟเวอร์ Node นี้เสิร์ฟได้ทั้ง `dist` และ `/api` จึงเลือกโฮสต์รวมกันหรือแยกหน้าเกมไป Pages ก็ได้

```sh
pnpm build
PORT=8787 DATA_DIR=/persistent/makhos ALLOWED_ORIGINS=https://froztorr.github.io pnpm server
```

คำสั่ง environment ด้านบนเป็นรูปแบบ Linux; บน PowerShell ใช้ `$env:PORT='8787'` ฯลฯ ก่อน `pnpm server` ตั้งค่า backend ผ่าน HTTPS reverse proxy ของผู้ให้บริการ และใช้ persistent disk กับ `DATA_DIR` เพื่อรักษาบัญชี/ของสะสม

มี `Dockerfile` สำหรับ build และรันโดยไม่ต้องติดตั้ง dependencies ใน runtime image:

```sh
docker build -t makhos .
docker run --rm -p 8787:8787 -v makhos-data:/data -e ALLOWED_ORIGINS=https://froztorr.github.io makhos
```

ตั้ง `ALLOWED_ORIGINS` เป็น origin เท่านั้น ไม่มี `/MakHos/` และคั่นด้วย comma หากมีหลาย origin ห้ามใส่ secret ใน Vite หรือ GitHub Pages

## ขอบเขตของต้นแบบ

- ยังไม่ใช่ระบบขายเงินจริง: ของตกแต่งใช้เหรียญในเกม ไม่มีการชำระเงิน
- บัญชีออนไลน์เป็น guest ที่ผูกกับ token ในเบราว์เซอร์ ยังไม่มีล็อกอินข้ามเครื่อง/กู้บัญชี ล้างข้อมูลเบราว์เซอร์แล้วเข้าบัญชีเดิมไม่ได้
- ห้องและคิวอยู่ในหน่วยความจำ รีสตาร์ต backend จะยุติห้อง ใช้ backend **หนึ่ง instance** ในรุ่นนี้ คะแนนและของสะสมคงอยู่ใน SQLite
- แรงค์เป็นต้นแบบ ยังไม่มีฤดูกาล ระบบตรวจจับปั๊มคะแนน/หลายบัญชี รายงานแชต หรือ matchmaking ตามช่วงคะแนน จึงยังไม่ควรเปิดแข่งขันสาธารณะจริงจัง
- บอตแต่ละด่านต่างกันที่ระดับค้นหาและภูมิประเทศ ยังไม่มีบทสนทนา/เรื่องราวยาว หรือโมเดลตัวละครวาดเฉพาะ
- ฟอนต์จาก Google Fonts มี Tahoma/sans-serif fallback ตัวเกมและโมเดลไม่อาศัย CDN ภายนอก
- ตรวจ responsive ในเบราว์เซอร์ได้ แต่การซูม แป้นพิมพ์ไทย ประสิทธิภาพ GPU และ safe area ต้องตรวจซ้ำบน iPhone/iPad/Android จริงก่อนเปิดใช้วงกว้าง

โครงสร้างหลัก: `src/rules.ts` กติกาที่แชร์กับเซิร์ฟเวอร์, `src/scene.ts` ภาพ 3D, `src/main.ts` UI, `server/index.ts` backend
